How to review

  1. Read each Dhivehi phrase against the English. Tick OK, or write the corrected Dhivehi in the last column.
  2. Check the tone is formal and suitable for an official union, and that terms are used the same way throughout (e.g. ޔޫނިއަން, މެމްބަރު, މައްސަލަ).
  3. Return the marked-up sheet. Corrections are made in the website's translation files (src/lib/dv.ts and src/lib/i18n.ts) and go live within minutes.
  4. Articles, campaigns, events and union names are not in this list. Editors add their Dhivehi versions in the editorial portal.
